# FAQ / 常見問題 / 자주 묻는 질문 / よくある質問

## English

**Is it free?** The public app requires no account, API key or paid backend. English–Chinese lookup, regional notes, lessons and local study tools are free. Sentence translation opens the official Google Translate website after your click, requiring internet and its availability. There is no unofficial API or automatic paid fallback. GitHub Pages has free-tier limits.

**Where is my data?** Name, collections, progress and history stay in this browser profile/device. No account sync, analytics or background clipboard watcher. Normal hosting requests reach GitHub; dictionary chunks load by initial rather than transmitting a full query. Clicking Google Translate sends the submitted text and selected languages to Google, subject to its own terms. Do not submit confidential material without authorization. The public app has no service-password form.

**Can data disappear?** Export JSON in Preferences before clearing data, private browsing, moving devices/origins or changing between web/native. Service secrets are excluded. Browser storage can be evicted; app updates can require an offline-pack download again. When storage fails, the session works in memory and warns you to export before closing.

**Does everything translate offline?** No: English–Chinese definitions and included notes/lessons do. Arbitrary sentences, every language pair, latest slang, grammar correction and AI replies do not. Changing the target does not translate existing Chinese notes. Historical data may contain errors; verify important usage and report corrections.

**What about installers?** Windows and both Mac architectures remain developer previews. CI is recorded separately from physical-device acceptance. Unsigned/unnotarized files may be blocked; use the web app and keep OS protection enabled. Browser PWA installation is optional and does not add native global shortcuts.

## 繁體中文

**免費嗎？** 公開版免帳號、API 金鑰與付費後端，包含英漢查字、用語、小課與本機學習功能。整句在你點擊後開啟官方 Google 翻譯，需要網路並受該站可用性影響。不用非官方 API，也不會自動轉付費服務。GitHub Pages 免費主機有使用量上限。

**資料去哪裡？** 名字、收藏、進度與紀錄留在這個瀏覽器／裝置。無帳號同步、分析追蹤與背景剪貼簿監聽。一般主機請求會到 GitHub；辭庫依字首載入，不傳完整查詢。按 Google 翻譯連結才交付該段文字與語言選擇，適用其條款。請勿傳送未經授權的機密內容。公開版不收服務通行碼。

**資料可能不見嗎？** 清除資料、無痕模式、切換裝置／網址或網頁／桌面版前，先在偏好設定匯出 JSON；不含服務密鑰。瀏覽器可回收快取，更新後也可能需重下載離線包。儲存失敗仍可暫用，畫面會提醒關閉前備份。

**所有內容可離線翻譯嗎？** 不能。英漢字義、內附筆記與課程可以；任意整句、所有語言對、最新流行語、文法校正與 AI 回覆不行。目標語言不會重寫繁中筆記。歷史資料可能有誤，重要用法請核對並回報修正。

**安裝檔呢？** Windows、兩種 Mac 架構維持開發預覽標示。CI 與實機驗收分開記錄。未正式簽章／公證可能被擋，保留系統保護並先用網頁版。瀏覽器 PWA 為選用，不提供原生全域快捷鍵。

## 한국어

**무료인가요?** 공개 앱은 계정·키·유료 백엔드가 필요 없습니다. 영중 사전·지역 표현·수업·로컬 학습을 포함합니다. 문장은 클릭 후 공식 Google 번역을 열며 인터넷과 가용성에 의존합니다. 비공식 API나 자동 유료 전환은 없고 무료 Pages에는 한도가 있습니다.

**데이터는 어디에?** 이름·저장·진도·기록은 현재 브라우저/기기 안에 있습니다. 동기화·분석 추적·백그라운드 클립보드 감시는 없습니다. 호스팅 요청은 GitHub에 도달하며 사전은 전체 검색어 대신 첫 글자별로 가져옵니다. Google 링크를 클릭하면 입력과 선택 언어가 Google로 전달되어 해당 약관이 적용됩니다. 허가 없는 기밀을 보내지 마세요. 서비스 비밀번호를 받지 않습니다.

**데이터가 사라질 수 있나요?** 삭제·시크릿 모드·기기/주소 변경·웹/네이티브 전환 전에 설정에서 JSON을 내보내세요. 서비스 비밀 정보는 제외됩니다. 브라우저가 캐시를 지우거나 업데이트 후 다시 다운로드해야 할 수 있습니다. 저장 실패 시 메모리로 동작하고 닫기 전 백업을 안내합니다.

**전부 오프라인인가요?** 영중 뜻풀이와 포함된 메모·수업만 가능합니다. 임의 문장·전체 언어 조합·최신 유행어·문법 교정·AI 답장은 아닙니다. 대상 선택은 기존 중국어 설명을 바꾸지 않습니다. 자료에 오류가 있을 수 있으니 중요한 용법은 확인하고 수정 제보를 해주세요.

**설치 파일은요?** Windows와 두 Mac은 개발 미리 보기이며 CI와 실제 기기 검증은 별개입니다. 서명/공증이 미완료라 차단되면 OS 보호를 유지하고 웹 앱을 쓰세요. 브라우저 PWA는 선택 사항이며 네이티브 전역 단축키는 없습니다.

## 日本語

**無料ですか？** 公開版はアカウント・キー・有料バックエンド不要で、英中辞典・地域表現・レッスン・ローカル学習を含みます。文はクリック後に公式Google翻訳を開き、接続と稼働に依存します。非公式APIや自動有料切替はなく、無料Pagesには上限があります。

**データはどこに？** 名前・単語・進捗・履歴は現在のブラウザ／端末内です。同期・分析追跡・背景のクリップボード監視はありません。ホストへの要求はGitHubに届き、辞典は全文ではなく頭文字単位で取得します。Googleリンクを押すと入力と選択言語をGoogleに送り同社の条件が適用されます。未許可の機密は送らないでください。サービスのパスワードは収集しません。

**データが消えることは？** 消去・プライベートモード・端末／URL変更・Web／ネイティブの切替前に設定からJSONを保存してください。サービスの秘密情報は含みません。ブラウザの削除や更新後にオフライン資料の再取得が必要になる場合があります。保存不可でもメモリ内で使え、閉じる前に保存を案内します。

**全部オフラインですか？** 英中語義と同梱の解説・レッスンが対象です。任意の文、全言語対、最新流行語、文法修正、AI返信は対象外です。翻訳先を変えても既存の中国語メモは変わりません。誤りがあり得るため重要な用法を確認し修正をお寄せください。

**インストーラーは？** Windowsと2種類のMacは開発プレビューで、CIと実機検証は別です。署名／公証未完了で拒否される場合はOS保護を維持してWeb版を使います。ブラウザPWAは任意でネイティブのグローバルショートカットはありません。
