Inline MyMemory translation requires first-use consent, a connection and available free quota. Enable it, then type and pause one second, or uncheck automatic mode and press 翻譯／查字. Google Translate is a separate fallback and requires a connection and may be unavailable in some regions. No unofficial fallback API or automatic paid request is used. The app retains the original query while the new translation tab is open; input is not promised to survive a full page reload. Local study data has no account sync. Export before switching devices, web/native versions, origins, private browsing or clearing data. Browser cache eviction and app updates may require downloading offline packs again.
